# Fractional-quadrature
We study quadrature formulas $\sum_{k=0}^{n}A_kf(x_k)$ for the Riemann--Liouville integral $\int_0^t(t-x)^{\alpha-1}f(x)\dd x$, $0&lt;\alpha&lt;1$, that are optimal in the sense of Sard in the Hilbert space $W_2^{(1,0)}(0,t)$ equipped with the semi-norm $\|f'+f\|_{L_2}$, for an \emph{arbitrary} set of nodes $0=x_0&lt;x_1&lt;\dots&lt;x_n=t$.
